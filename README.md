# 말씀에 쉬다 · 말씀이 찬양이 되는 순간

한 단어로 말씀을 묵상하고, AI로 어린이 찬양·CCM을 만들고, 링크로 누구에게나 들려주는 웹앱입니다.

**앱 주소:** https://silkim1220-source.github.io/word-rest/

## 앱 고치는 방법 (어느 브라우저·기기에서나)

### 1. 화면 글자·색 바꾸기 (쉬움)
1. 이 저장소에서 **config.js** 를 누르고 오른쪽 위 연필(✏️) 버튼을 누릅니다.
2. 따옴표 '...' 안의 글자나 색 코드만 바꿉니다.
3. **Commit changes** → 다시 **Commit changes** 를 누릅니다.
4. 1~2분 뒤 앱을 새로고침하면 반영됩니다.

### 2. 화면 구성·디자인·기능
| 파일 | 내용 |
|---|---|
| index.html | 화면 문구·버튼·안내문 |
| app.css | 디자인 (글꼴 크기·여백·색) |
| app-01.js ~ app-09.js | 기능 코드 (원고·음악·이미지·영상·공유) |
| web.js | 웹앱 기능 (듣기 페이지, 앱 설치, 연결 유지) |
| edit.js | 내용 고치기·자동 저장·다른 기기에서 이어서 편집 |
| lame.min.js | MP3 만들기 라이브러리 (고치지 마세요) |
| bg.jpg | 배경 사진 (같은 이름으로 올리면 교체) |

PC에서는 저장소 화면에서 키보드 **.** (마침표)를 누르면 전체 편집기가 열립니다.

### 되돌리기
잘못 고쳤다면 **Commits** (변경 기록)에서 이전 버전을 확인할 수 있습니다.

## 개인정보
- 비밀 API 키는 코드에 없습니다. 음악 에이전트 연결 토큰은 사용하는 기기의 브라우저에만 저장됩니다.
- 보관함은 각 브라우저에 저장되며, ‘다른 기기에서 이어서 편집’ 링크(30일)나 파일로 옮길 수 있습니다.
